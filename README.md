# Greenfield School Results Analysis

## Project Overview
This project uses Microsoft Excel to analyse students' academic performance at Greenfield School across six classes and three academic terms.

The analysis focuses on identifying academic strengths, areas requiring improvement, student progress, and students who may need additional academic support.

## Project Objectives
- Clean and organise students' academic records.
- Evaluate class and subject performance.
- Track students' academic progress across three terms.
- Identify students who may be at risk academically.
- Present findings through an interactive Excel dashboard.

## Dataset Description
- Total students: 240
- Total records: 720
- Classes: JSS1A, JSS1B, JSS2A, JSS2B, JSS3A and JSS3B
- Academic terms: First, Second and Third Term
- Subjects: Maths, English, Basic Science, Social Studies, Computer Studies and Civic Education.

## Tools and Techniques
**Tool:** Microsoft Excel

Techniques used:
- Data cleaning and standardisation
- Excel formulas and functions
- Conditional formatting
- PivotTables and PivotCharts
- Performance ranking
- Data analysis and visualisation
- Interactive dashboard development

## Analysis Performed
1. Data cleaning and preparation.
2. Class performance analysis.
3. Subject performance analysis.
4. Student improvement analysis across terms.
5. Identification of at-risk students.
6. Student ranking.
7. Dashboard development.

## Key Findings
- Overall average score: 62.34%
- Overall pass rate: 84.86%
- Students identified as at risk: 32
- Highest-performing subject: Civic Education
- Lowest-performing subject: Maths
- Best-performing class in Third Term: JSS3B
- Class requiring the most improvement in Third Term: JSS3A

## Dashboard
The Excel dashboard presents:
- Average performance by class and term.
- Average scores by subject.
- Academic performance trends across the three terms.

## Recommendation
The school should strengthen teaching strategies in weaker subject areas, provide targeted academic support to struggling students, and regularly monitor academic progress.
